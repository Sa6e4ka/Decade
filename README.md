# Decentralized Classifieds Board
### This project is a decentralized classifieds board that enables users to post listings and communicate securely without relying on centralized platforms.

## Features

### Decentralized Listings – Users can post classified ads directly on the blockchain.

### Decentralized Image Storage – Images are stored securely using Pinata, ensuring censorship resistance and availability.

### Blockchain Interaction – Powered by Thirdweb, enabling seamless smart contract interaction.

### Built-in Decentralized Messenger – Secure, wallet-based messaging using the XMTP protocol.

### Modern Frontend –Developed with React.js (Vite) and styled using Chakra UI.

## Status

### This project is currently in development.
